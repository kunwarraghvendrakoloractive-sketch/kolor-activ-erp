Prefix identifying company plant (e.g., KA for Kolor Activ).
2. Line Code
Short line identifier (e.g., L1=Line A, L2=Line B, PK=Packaging).
3. Production Date
Formatted date stamp DDMMYY (e.g., 050826 = 05 Aug 2026).
4. Shift Identifier
Shift code: R (Regular 09:30 AM–06:00 PM), OT (Overtime).
5. Daily Sequence
Padded incremental run counter (e.g., 001, 002).
